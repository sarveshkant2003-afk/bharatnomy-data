# RBI Handbook of Statistics on Indian States (selected tables)

State-level series republished by the Reserve Bank of India. The original agency is named under each file.

## rbi-hsis_factories_state_2004-05-to-2023-24.csv

Number of factories per state, from the Annual Survey of Industries (MoSPI).

- **Table:** RBI Handbook 2024-25, Table 116 "State-wise Number of Factories"
- **Link:** https://rbi.org.in/scripts/PublicationsView.aspx?id=23565
- **Downloaded:** 19 Oct 2026

| Column | Meaning |
|---|---|
| `state_ut` | State or Union Territory. `All India` = national total |
| `year` | Financial year |
| `factories` | Number of factories |
| `source_flag` | `not_applicable` = state/UT not separate that year; `not_available` = not covered |

## rbi-hsis_net-sown-area_state_2004-05-to-2020-21.csv

Land sown with crops in a year, counting land sown more than once only once. Original data: Land Use Statistics, MoA&FW.

- **Table:** RBI Handbook 2022-23, Table 56 "State-wise Pattern of Land Use - Net Sown Area"
- **Link:** https://rbi.org.in/Scripts/PublicationsView.aspx?id=22120
- **Downloaded:** 19 Oct 2026

| Column | Meaning |
|---|---|
| `state_ut` | State or Union Territory. `All India` = national total |
| `year` | Agricultural year (July to June) |
| `net_sown_area_000_ha` | Net sown area, thousand hectares |
| `source_flag` | `estimated`, `provisional`, or `not_applicable` (state did not exist) |
